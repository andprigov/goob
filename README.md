# Data Crawler

Data Crawler is a modular Python application that simulates collecting structured information from multiple web sources.

The project demonstrates a layered architecture where sources are loaded, parsed, cleaned and stored as structured records. It focuses on code organization rather than real web scraping.

## Features

- Multiple data sources
- HTML parsing simulation
- Metadata extraction
- Keyword analysis
- JSON export
- Crawl statistics
